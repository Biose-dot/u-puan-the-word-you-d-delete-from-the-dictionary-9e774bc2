# The Word You'd Delete From the Dictionary — `irregardless`

The one word to erase from the dictionary forever: **irregardless** —
a word that was never a word in the first place. Deleting it costs the
language nothing and fixes it at the same time.

## Entry

`main.py` (pure Python 3 stdlib, no network) copies the one word from
`entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

```sh
python3 main.py
```
